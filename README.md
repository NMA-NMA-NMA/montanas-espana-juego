# 🏔️ Montañas de España - Juego Educativo

Un juego interactivo para que los niños aprendan a identificar las principales zonas montañosas de España.

## 🎮 Cómo Jugar

1. **Selecciona** el nombre de una montaña en la lista
2. **Haz clic** en la zona correcta del mapa
3. **¡Acierta!** para sumar puntos
4. Completa todas las zonas para ganar

## 📚 Notas Educativas

Este juego fue creado para ayudar a los niños a aprender geografía de una forma divertida e interactiva. Incluye:

- **Sistemas montañosos principales**: Pirineos, Cordillera Cantábrica, Sistema Central, etc.
- **Depresiones**: Depresión del Ebro y Guadalquivir
- **Submesetas**: Norte y Sur
- **Islas**: Representación del relieve insular con Canarias
