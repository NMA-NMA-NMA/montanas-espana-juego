## 🎮 Descripción

Un juego interactivo para que los niños aprendan a identificar las principales zonas montañosas y geográficas de España de forma visual y entretenida.

### Características principales:

✅ **Mapa Real Interactivo** - Usando OpenStreetMap y Leaflet
✅ **17 Zonas Geográficas** - Todas correctamente posicionadas
✅ **Interfaz Intuitiva** - Diseñada para niños y estudiantes
✅ **Sistema de Puntuación** - Retroalimentación inmediata
✅ **Responsive** - Funciona en móvil, tablet y escritorio
✅ **Animaciones Suaves** - Transiciones visuales agradables
✅ **Totalmente Gratuito** - Propósito educativo sin ánimo de lucro

---

## 🎯 Cómo Jugar

1. **Selecciona** el nombre de una montaña o zona en la lista del lado derecho
2. **Haz clic** en la ubicación correcta en el mapa interactivo
3. **¡Acierta!** para sumar puntos y cambiar el color a verde
4. Completa todas las 17 zonas para ganar y ver el mensaje de felicitaciones

7. **Cordillera del Guadarrama** - Centro
8. **Sistema Central** - Centro
9. **Montes de Toledo** - Centro-Sur
10. **Sierra Morena** - Sur
11. **Cordillera Penibética** - Sureste
12. **Montes de Córdoba** - Sur

### Depresiones y Submesetas:
13. **Depresión del Ebro** - Noreste
14. **Submeseta Norte** - Centro-Norte
